# 追光日历

这是一个无需安装、双击即可使用的追剧日历网页应用。

## 使用方法

1. 双击 `index.html`，使用 Chrome、Edge、Safari 等现代浏览器打开。
2. 点击「添加剧集」，填写剧名、首播日期、每周更新日和总集数。
3. 在月历中点击日期，可查看当天的更新并勾选观看状态。
4. 点击「开启提醒」后，保持页面打开即可收到更新提醒。
5. 点击「导出日历」，可下载 `.ics` 文件，再导入手机或电脑自带日历。导入后即使关闭网页，也能按系统日历规则提醒。

## 数据说明

- 片单和观看记录仅保存在当前浏览器的本地存储中。
- 更换浏览器、清除浏览器数据或使用无痕模式后，记录不会自动同步。
- 首次打开会显示已核实排播的《后会友期》和《Fool in Love》；旧的示例剧集会自动移除。

## AI 自动识别

1. 首次使用时点击「配置 AI 服务」，填入自己的 OpenAI API Key。
2. 回到添加剧集窗口，只输入剧名并点击「AI 联网识别」。
3. AI 会联网搜索平台、播放时间、集数、正片及会员内容排期，并预填表单。
4. 检查结果与来源，确认后保存。

API Key 默认只在当前标签页会话中使用；勾选“记住密钥”后才会保存在当前浏览器。密钥不写入网页源码或 GitHub 仓库。AI 请求通过部署网站的无状态代理转发，代理不会保存密钥或排播数据。
